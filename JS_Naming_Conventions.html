JavaScript Naming Conventions

Case Example Valid in JS?
camelCase firstName Yes (standard for variables/functions)
PascalCase FirstName Yes (standard for classes/constructors)
snake_case first_name Yes (allowed, less common)
SCREAMING_SNAKE_CASE FIRST_NAME Yes (for constants)
kebab-case first-name No (SyntaxError in JS)
Hungarian Notation strFirstName Yes (older style, avoid)
Train-Case First-Name No (used in HTTP headers)
